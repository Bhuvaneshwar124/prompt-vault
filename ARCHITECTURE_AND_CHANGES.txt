1. CORE PRODUCT VISION & IDEA
--------------------------------------------------------------------------------
Problem Solved:
  Engineers & creators frequently lose high-performing AI prompts and valuable conversation context 
  scattered across ChatGPT, Gemini, Groq, Claude, and DeepSeek. Re-typing prompts and variable 
  parameters causes friction and inconsistent AI outputs.

Solution:
  Prompt Vault is an enterprise AI prompt engine designed to:
    1. Index external AI chat session locations (storing exact chat URLs and conversation summaries).
    2. Populate dynamic {{variable_placeholders}} in 1-click using an interactive modal.
    3. Share prompts in a Public Tech Stack Marketplace featuring 5-star ratings & developer reviews.
    4. Provide a private, JWT-secured vault for personal prompt organization.


2. SYSTEM ARCHITECTURE & TECHNICAL FLOW
--------------------------------------------------------------------------------
Architecture Overview:

   [ React 18 + TypeScript + Vite ]  <--- (Axios REST + JWT Bearer Token) --->  [ Spring Boot 3 Java Backend ]
                 |                                                                            |
    +------------+------------+                                                      +--------+--------+
    |                         |                                                      |                 |
  (Landing & Explore)    (My Indexer)                                           (H2/PostgreSQL DB) (Spring Security)
  Public Marketplace     Personal Vault &                                       Prompts, Users,    JWT Authentication
  & 5-Star Ratings       AI Chat Indexer                                        Ratings, Comments  & BCrypt Password

Frontend Stack (React 18 + TypeScript + Tailwind CSS):
  - LandingPage.tsx          : Product overview with live interactive variable filler demo & CTA.
  - ExplorePage.tsx          : Public Tech Stack Marketplace (/explore) filtered by React, Java, 
                               Python, SQL, Docker, and AI tools with star ratings & reviews.
  - DashboardPage.tsx        : Personal Vault & AI Chat Location Indexer (/dashboard).
  - PromptCard.tsx           : Dual-mode card component (mode="indexer" vs mode="community").
  - VariableFillerModal.tsx  : Dynamic parser and form generator for {{variable_name}} placeholders.
  - PromptDetailsModal.tsx    : Full prompt inspector, 5-star rating widget, and community discussion.
  - Navbar.tsx & Footer.tsx  : Glassmorphism header and universal footer.

Backend Stack (Spring Boot 3 + JPA + Security):
  - PromptController.java    : REST API for prompt search, CRUD, and favorite toggling.
  - CommunityController.java : REST API for 1-5 star ratings, comments/reviews, and like counts.
  - WebSecurityConfig.java   : Security filter chain permitting public GET requests for /api/v1/prompts/**.
  - PromptSpecification.java : Dynamic Specification for tech stack, keyword, and AI tool filtering.
  - DataInitializer.java     : Seeds default roles (ROLE_USER, ROLE_ADMIN), admin user, and sample prompts.

Data Models:
  - User          : User credentials, roles, and authorization profiles.
  - Prompt        : Title, prompt text, system instruction, target model, AI tool, external chat URL, 
                    chat summary, isPublic, isFavorite, viewCount, and likeCount.
  - PromptRating  : 1-5 star ratings per prompt per user.
  - Comment       : Community reviews and comments per prompt.

4. INTEGRATION & DEPLOYMENT ROADMAP
--------------------------------------------------------------------------------
Milestone 1: Local Setup (Current State)
  - Frontend Dev Server : http://localhost:3000 (npm run dev)
  - Backend API Server  : http://localhost:8080 (mvnw.cmd spring-boot:run)
  - In-Memory Database  : http://localhost:8080/h2-console

Milestone 2: Direct AI API Integration (OpenAI / Gemini / Groq)
  - Create AiGenerationController in Spring Boot.
  - Send compiled prompt text with variable values to OpenAI API (gpt-4o), Gemini API (gemini-1.5-pro), 
    or Groq API (llama-3.3-70b) and return generated responses directly inside Prompt Vault.

Milestone 3: Production Cloud Deployment
  - Frontend : Host built bundle (dist) on Vercel or Netlify (setting VITE_API_URL).
  - Backend  : Deploy Spring Boot JAR to Render.com, Railway.app, or AWS EC2.
  - Database : Connect to a hosted PostgreSQL instance on Supabase or Render.
